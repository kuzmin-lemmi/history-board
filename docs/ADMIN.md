# «Доска истории»: памятка для системного администратора школы

«Доска истории» — бесплатная программа для уроков истории на Windows 10/11 (x64). Программа автономная: .NET и все библиотеки встроены в один файл. Для работы не нужны ни интернет, ни регистрация, ни учётные записи. Служб, драйверов и автозапуска программа не устанавливает. Данные об использовании не собирает.

## Что и куда устанавливается

Установщик `HistoryBoard-Setup-win-x64.exe` ставит программу **для текущего пользователя, без прав администратора**:

| Что | Где |
| --- | --- |
| Программа | `%LOCALAPPDATA%\Programs\HistoryBoard\Историческая доска.exe` (и значок `HistoryBoard-1.1.ico`) |
| Ярлык в меню «Пуск» | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Доска истории\` |
| Ярлык на рабочем столе | по желанию пользователя |
| Запись «Установка и удаление программ» | `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\HistoryBoard` |
| Связь с файлами уроков `.hboard` | `HKCU\Software\Classes\.hboard` и `HKCU\Software\Classes\HistoryBoard.Lesson` |
| Данные пользователя | `%LOCALAPPDATA%\HistoryBoard\Data`: автосохранение и его история, библиотека уроков, горячие клавиши, примеры уроков, скачанные обновления (`Updates`) |
| Распакованные библиотеки | `%TEMP%\.net\HistoryBoard\…` — при первом запуске файл распаковывает встроенные компоненты, в том числе `pdfium.dll` для чтения PDF |

Сами уроки сохраняются туда, куда их сохраняет учитель (файлы `.hboard`). При удалении программы уроки и данные остаются.

## Сеть

Программа обращается в интернет только для проверки и скачивания обновлений, по HTTPS (порт 443):

- `api.github.com` — проверка последней версии;
- `github.com`, `release-assets.githubusercontent.com`, `objects.githubusercontent.com` — скачивание установщика новой версии.

Если эти адреса закрыты, программа полностью работает, просто не предлагает обновления. Перед установкой скачанное обновление проверяется по размеру и контрольной сумме SHA-256.

## Если запуск программ из профиля пользователя запрещён (AppLocker, SRP)

Во многих школах разрешён запуск программ только из `C:\Program Files` и `C:\Windows`. Установщик ставит программу в профиль пользователя, поэтому там она не запустится. Есть два решения.

**1. Установка для всех пользователей (рекомендуется).** Скопируйте файл в папку Program Files под любым именем, в котором нет слов «Setup» и «Установить», например:

```
C:\Program Files\Доска истории\Доска истории.exe
```

С таким именем файл сразу открывает доску, а не установщик. Создайте ярлык для пользователей. Каждый учитель будет хранить свои данные в своём `%LOCALAPPDATA%\HistoryBoard\Data`. Связь с файлами `.hboard` при таком способе не создаётся: уроки открываются кнопкой «Уроки» или «Открыть файл» в программе.

Новые версии в этом случае обновляйте сами — заменой файла. Кнопка обновления в программе скачает установщик в профиль пользователя, но при ваших правилах он не запустится, и это ожидаемо.

**2. Правило по хешу файла.** Можно разрешить установщик и программу правилом AppLocker по хешу. Хеш меняется с каждой версией, поэтому правило придётся обновлять.

Правила AppLocker для DLL по умолчанию выключены. Если вы их включали, разрешите также распакованные библиотеки в `%TEMP%\.net\HistoryBoard\`.

## SmartScreen и антивирус

Пока у программы нет цифровой подписи, Windows SmartScreen может показать «Windows защитила ваш компьютер». Это предупреждение о новой неподписанной программе, а не о найденной угрозе. Пользователь может нажать «Подробнее» → «Выполнить в любом случае». В управляемой сети лучше разрешить файл по хешу. Отключать антивирус не нужно и не следует.

## Как проверить подлинность файла

Скачивайте программу только со страницы релизов: <https://github.com/kuzmin-lemmi/history-board/releases>. К каждому установщику приложен файл `.sha256`. Проверка в PowerShell:

```powershell
Get-FileHash .\HistoryBoard-Setup-win-x64.exe -Algorithm SHA256
Get-Content .\HistoryBoard-Setup-win-x64.exe.sha256
```

Значения должны совпасть. Исходный код программы открыт и находится в том же репозитории.

## Удаление

«Параметры → Приложения → Доска истории → Удалить» или команда:

```
"%LOCALAPPDATA%\Programs\HistoryBoard\Историческая доска.exe" --uninstall
```

Удаляются программа, ярлыки и записи реестра в `HKCU`. Уроки и `%LOCALAPPDATA%\HistoryBoard` остаются; их можно удалить вручную. При установке в Program Files достаточно удалить файл и ярлык.

## Тихая установка

Отдельного тихого режима у установщика пока нет. Для массового развёртывания используйте копирование файла в Program Files (способ 1 выше).
