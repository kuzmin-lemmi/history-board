# Доска истории · 1.2.0

Бесконечная интерактивная доска для учителя истории. Windows 10/11, x64. C# / WPF / .NET 10. Работа с уроками не требует браузера, регистрации и интернета. Интернет нужен только для проверки и скачивания обновлений.

Репозиторий: [kuzmin-lemmi/history-board](https://github.com/kuzmin-lemmi/history-board). [Скачать последний релиз](https://github.com/kuzmin-lemmi/history-board/releases/latest). Пути установки и автосохранения сохранены для совместимости с предыдущими версиями.

## Новые возможности рабочей версии

- **Настройки клавиш:** кнопка **⚙** вверху окна открывает поиск по командам. Нажмите на текущее сочетание, введите новое и нажмите **«Сохранить»**. Совпадающие сочетания в одном режиме не принимаются. **«Убрать»** отключает сочетание, **«Сбросить все»** возвращает стандартные назначения, **«Отмена»** оставляет настройки без изменений. Назначение заменяет все прежние варианты выбранной команды. Подсказки кнопок, меню и справка обновляются сразу. Указанные ниже сочетания — стандартные; их можно изменить.
- **Ctrl+V:** вставляет скопированное изображение из браузера, снимок экрана или скопированные объекты доски. Внутри текстового поля сохраняется обычная вставка текста. Изображения встраиваются в `.hboard` и остаются доступны без исходного файла.
- **Множественный выбор:** инструмент «Выбор» (V), рамка на свободном месте или Shift+клик. Рамка выбирает пересекающиеся объекты. Выделение перемещается и удаляется целиком; Ctrl+A выделяет всё.
- **Копии и группы:** Ctrl+C / Ctrl+V копируют и вставляют выделение, Ctrl+D дублирует со сдвигом, Ctrl+G объединяет в группу, Ctrl+Shift+G разбирает группу. Команды доступны и в меню **«Действия»**. Группы сохраняются в уроке. Если выделение содержит закреплённый объект, перемещение и удаление защищены; кнопка «Открепить» снимает защиту со всего выделения.
- **Библиотека:** при обычном запуске открывается список последних 60 сохранённых или открытых уроков с миниатюрами, поиском и датой открытия. Кнопка **«Уроки»** возвращает к списку; **«Открыть файл…»** или Ctrl+O открывают другой `.hboard`. «Убрать из списка» оставляет сам файл на месте. Если файл перенесён, откройте его из нового расположения.
- **Фон:** по умолчанию используется мелкая клетка на тёплой светлой бумаге. Меню **«Фон»** предлагает также точки, линейку, однотонную тёплую бумагу и белый лист. Узор привязан к координатам доски, сохраняется в уроке и экспортируется в PNG. На очень мелком масштабе клетка укрупняется для читаемости.

Старые уроки продолжают открываться. Для сохранения новых групп и фонов используйте эту или более новую версию приложения. Инструкции разработчика: [DEVELOPING.md](DEVELOPING.md).

Назначения клавиш сохраняются на этом компьютере в `%LOCALAPPDATA%\HistoryBoard\Data\shortcuts.json`, отдельно от файлов уроков. В редакторе и показе могут использоваться одинаковые сочетания для разных действий. Esc завершает ввод или показ, а Пробел + мышь перемещают доску. В текстовых полях сохраняются обычные команды набора текста; сохранение, настройки и полный экран доступны через подходящие назначенные сочетания с Ctrl/Alt или F-клавиши.

## Обновления из программы

Кнопка **↻** вверху окна открывает проверку обновлений. При запуске программа также проверяет последний стабильный релиз в фоне; если есть новая версия, кнопка меняется на **«↻ Новая»**. Отсутствие интернета не мешает уроку.

Нажмите **«Скачать обновление»**. После загрузки программа сверит размер и SHA-256, затем предложит **«Сохранить урок и установить»**. Текущий урок сохранится, доска закроется и откроется установщик. Неполные или повреждённые файлы не запускаются. Загрузку можно отменить.

Черновики и предварительные релизы не предлагаются. Проверка использует публичный GitHub API без токенов пользователя. Если установщик ещё собирается или GitHub временно ограничил запросы, повторите проверку позже.

## Как выпустить новую версию

1. Отправьте изменения в ветку `main`. Проверка **Build and test** должна завершиться успешно.
2. На GitHub откройте **Releases → Draft a new release**, создайте новый тег вида **`v1.2.1`**, выберите `main`, добавьте описание и опубликуйте обычный стабильный релиз.
3. Workflow **Build release installer** автоматически соберёт приложение с версией из тега, выполнит проверки и прикрепит `HistoryBoard-Setup-win-x64.exe` и файл `.sha256` к релизу.
4. После завершения workflow пользователи смогут скачать эту версию из программы. Номер нового релиза должен быть выше установленного. Исходники и рабочие файлы приложения в GitHub не отправляются пользователями.

При ручной сборке используйте `./build.ps1 -Version 1.2.1` и прикрепите к релизу указанные `.exe` и `.sha256`. Автоматическую загрузку файлов можно повторить через **Actions → Build release installer → Run workflow**, указав существующий тег.

## Установка и обновление

Закройте предыдущую версию, откройте `Готовое приложение\Установить доску.exe` и нажмите **«Установить и открыть»**. Программа появится в меню «Пуск». По желанию установщик создаёт ярлык на рабочем столе с новой иконкой. Права администратора и отдельная установка .NET не нужны. Сохранённые уроки и автосохранение остаются на месте.

Для работы без установки скопируйте этот же файл в отдельную папку и переименуйте в `Доска истории.exe`. Первый запуск распаковывает внутренние компоненты; затем используется кэш Windows.

## Перемещение по доске

**Пробел + левая кнопка мыши**, **средняя кнопка мыши** или инструмент **«Рука» (H)** позволяют перетаскивать поле. Текст и изображения остаются в своих координатах. Во время ввода текста пробел вводит обычный пробел; для перемещения сначала завершите ввод клавишей Esc.

В режиме «Выбор» или «Рука» колёсико двигает вид вверх/вниз, **Shift + колёсико** — влево/вправо. **Ctrl + колёсико** меняет масштаб вокруг указателя. Кнопка **«Всё» / Ctrl+0** показывает все объекты.

Поле не создаётся как огромная картинка: камера перемещается над векторными объектами. Технический предел координат — около миллиарда условных пикселей в каждую сторону; для обычных уроков границ поля не видно.

## Текст, карты и пометки

- **Текст (T):** кликните и пишите. Колёсико меняет размер, Enter добавляет строку, Esc или Ctrl+Enter завершают ввод. Двойной клик по надписи инструментом «Выбор» открывает редактирование.
- **Список (L):** пункты вводятся с новой строки. Нумерация появляется после завершения ввода.
- **Карта:** кнопка «＋ Карта» / Ctrl+M или перетаскивание изображения в окно. Поддерживаются PNG, JPG, BMP и TIFF. Карта добавляется в текущую область за надписями и пометками.
- **Карандаш (P):** рисуйте с зажатой левой кнопкой. Колёсико меняет толщину. Цвета — наверху.
- **Стрелка (A):** протяните от начала к концу. Shift выравнивает направление с шагом 45°.
- **Выбор (V):** перемещайте объекты. Нижний правый угол карты меняет её размер с сохранением пропорций. Delete удаляет выбранное.
- **Ластик (E):** удаляет пометку или надпись целиком, не затрагивая карту.

Выделите объект и нажмите **«Закрепить» / Ctrl+L**, чтобы защитить его от перемещения, редактирования и удаления. **«Открепить»** возвращает возможность изменений. Рисовать поверх закреплённой карты можно.

## Кадры и презентация

1. Разместите материалы и выберите нужную область и масштаб.
2. Нажмите **«＋ Кадр» / Ctrl+Enter**. Запомнится весь текущий вид.
3. Переместитесь к следующим материалам и добавьте ещё один кадр.
4. Нажмите **«▷ Показ» / F5**. Панели редактирования скроются. **← / →**, **Page Up / Page Down** или кнопки внизу переключают кадры. Home/End — первый/последний кадр. **Esc** завершает показ.

В редакторе клик по кадру возвращает его вид, двойной клик меняет название. Правая кнопка позволяет поменять порядок, запомнить новый вид или удалить кадр. Удаление кадра оставляет все объекты на доске. Можно сохранить до 500 кадров.

## Сохранение

**Ctrl+S** сохраняет в один `.hboard`-файл все изображения, надписи, пометки, закрепления, кадры и положение камеры. Исходные файлы карт после этого не нужны. **Ctrl+Shift+S** сохраняет копию. Уроки из версии 1.0 открываются в новой версии; новые файлы следует открывать в версии 1.1 или новее.

Последний урок и положение камеры автоматически сохраняются в `%LOCALAPPDATA%\HistoryBoard\Data` и восстанавливаются при следующем запуске. Для хранения нескольких уроков сохраняйте отдельные `.hboard`-файлы.

Меню **PNG** экспортирует текущий вид, выбранный кадр или все объекты. Очень большой экспорт уменьшается до 8192 пикселей по стороне и 32 мегапикселей суммарно.

**Ctrl+Z / Ctrl+Y** — отменить / повторить. **F11** — весь экран без перехода в режим показа. Клавиши инструментов работают при английской раскладке.

Удаление: «Параметры Windows → Приложения → Доска истории → Удалить». Уроки и автосохранение остаются на компьютере.

## Сборка и проверка

Нужны .NET SDK 10 для Windows и PowerShell 7. Выполните `pwsh -NoProfile -File .\build.ps1`. Интернет нужен разработчику для первой загрузки официальных компонентов .NET. Готовое приложение работает автономно. Для публикации подготовлены `HistoryBoard-Setup-win-x64.exe` и его SHA-256 в папке «Готовое приложение».

Проверки автономной сборки: `./test-app.ps1`. Также доступны `dotnet bin\Release\net10.0-windows\win-x64\HistoryBoard.dll --self-test test-results` (путь зависит от конфигурации). Результаты, примеры уроков и изображения интерфейса записываются в указанную папку. Проверки обновлений используют локальные HTTP-ответы, не скачивают реальные установщики и не выполняют установку.

Каждый объект использует отдельный WPF DrawingVisual. Перемещение камеры меняет одну матрицу, без повторного размещения объектов. При рисовании обновляется текущий штрих. Большие карты декодируются с рабочей шириной до 3600 пикселей; чтение и сохранение файлов выполняются в фоне. История отмены ограничена 60 действиями.
